# 项目评审与优化（2026-10-08）

项目的编辑模型、排版桥接、服务与界面已有清晰分层，并提供真实 WebEngine 交互测试。本轮优先处理数据保存和启动稳定性，未进行整体架构重写。

## 已处理

| 问题 | 修改 |
| --- | --- |
| 主窗口缺少 QTimer 导入，默认自动检查更新触发 NameError | 补全导入 |
| 延迟检查更新回调在窗口销毁后仍可能执行 | 使用由窗口持有的单次定时器，随窗口销毁 |
| 文档和设置直接覆盖写入，失败可能截断原文件 | 同目录临时文件完整写入、flush/fsync 后原子替换，失败清理临时文件 |
| 保存失败没有用户反馈 | 返回保存失败并保留编辑状态，提示错误；自动保存失败也保留修改 |
| 已安排的自动保存不检查最新开关 | 定时器触发时重新检查开关，跳过无修改文档 |
| 合法 JSON 但非对象的设置文件导致启动异常 | 回退默认设置 |
| 目录链接循环导致反复遍历 | 按解析后的目录路径去重 |
| 空搜索词匹配全部内容 | 空查询及非正结果上限立即返回 |

## 第二轮：搜索调度与资源占用

- 增加 SearchController，每次只运行一个任务；连续请求仅保留最新的等待任务，取消过期搜索并按请求编号丢弃旧结果。
- 使用 QObject 的槽在主线程交付搜索结果，避免后台线程操作界面；线程完成后释放资源。
- 编辑查询词、清空查询词或切换文件夹时取消旧请求并清空结果，避免把旧范围的结果显示在新范围下。
- 正文逐行读取，并在目录入口、文件间和行间检查取消状态，减少整篇读取和拆分产生的中间内存。
- 窗口确认退出后取消搜索并等待线程结束。若两秒内仍未退出，则保留窗口和线程，提示稍后关闭，避免销毁仍在运行的线程。操作系统层面的文件 I/O 阻塞无法通过协作取消立即打断。

新增 tests/test_search_controller.py 覆盖最新请求顺序、GUI 线程回调、正常取消、超时保留线程、查询和文件夹变化清理结果，以及逐行取消。

本轮系统 Python 的 PySide6 初始化文件与 shiboken6 依赖缺失，故在项目内 .test-deps 安装独立 Qt 测试依赖验证；该目录已加入 .gitignore，系统 Python 安装未修改。

第二轮最终验证：unittest 51 项中 50 项通过、1 项因目录链接权限跳过；编辑变换 33 项、插件 8 项、搜索 11 项检查通过。Python 编译检查和 git diff --check 通过。

复现当前独立依赖环境的回归命令：

```powershell
python -c 'import sys, runpy; sys.path.insert(0, ".test-deps"); sys.argv = ["unittest", "discover", "-s", "tests"]; runpy.run_module("unittest", run_name="__main__")'
```

## 第三轮：编辑体验与界面效果

- 原生菜单、标签、侧边栏、查找栏与状态栏跟随七套文档主题；源码文本、行号区及滚动条同步配色。新建和已打开的标签都应用当前偏好。
- 配置中文界面字体回退；在无法枚举系统字体的 Windows 离屏测试环境中尝试加载本机微软雅黑字体。
- 标签栏增加 + 新建入口、长标题省略与完整路径提示；更新后台标签的未保存标记。
- 状态栏区分未命名文档与已保存文件，模式按钮可点击切换，附快捷键提示。
- 切换编辑模式时屏蔽装载源码引发的修改通知，避免把未编辑的文档误标为未保存。
- 标签切换时立即更新大纲；后台标签的延迟刷新不再覆盖当前大纲。
- 查找显示匹配、未找到和源码搜索回到开头/末尾的反馈；未命中时保留原光标和选区。渲染模式读取 Qt 的结果对象显示匹配数量，过期回调不能更新新的查找反馈。修改关键词或关闭查找时清理旧的渲染高亮。
- 渲染模式隐藏源码替换控件；源码替换兼容查找的大小写不敏感行为，空查询不执行替换。

新增 tests/test_ui_experience.py 的六项交互回归，覆盖模式切换、多标签大纲、查找与替换、真实 WebEngine 查找和主题应用；同时检查源码视口实际绘制的背景色。最终 unittest 57 项中 56 项通过、1 项因目录链接权限跳过；插件 8 项与搜索 11 项脚本检查通过。浅色、深色与源码截图均已视觉复查。源码已修改，现有安装程序尚未重新构建。

## 第四轮：输入细节与文件工作流

- 修复打开文件后调用缺失的最近文件方法；文件菜单新增“最近打开”，记录打开及保存的文件，去重保留最近 20 项，选择已打开文件直接定位现有标签。
- 文件打开失败显示路径与原因，保留现有文档和标签；兼容 UTF-8 BOM。其他编码不自动猜测，仍需转换为 UTF-8。恢复上次文件失败时回到欢迎文档。
- 关闭未保存提示时点击关闭或取消会保留标签及窗口，只有明确选择不保存才放弃修改。
- 另存为后更新文件监视与最近文件；阻止另存为覆盖另一个已打开标签所关联的文件。文档写入成功但最近记录写入失败时单独提示。
- 记录已确认的磁盘内容，忽略本应用保存产生的延迟通知；真正的外部修改仍正常提示或重新加载。
- 两种模式遵循字号与符号自动配对设置；新增缩进宽度与配对开关。源码 Tab/Shift+Tab 使用指定宽度，支持配对包装选区、空配对整体退格和跳过已有闭括号；配对插入可一次撤销。普通渲染退格保留浏览器的 Unicode 字素删除行为。
- 源码切换到渲染再返回，若内容未被修改，则保留源码光标、选区及原生撤销历史；若渲染模式修改了内容，源码需要重新装载，原生撤销历史仍会重置。
- 设置加载过滤错误字段类型及无效列表成员，字号限制为 12–28，缩进宽度为 1–8，避免损坏的设置破坏输入或布局。
- 动态最近菜单刷新后，命令面板跳过已销毁的菜单项；异步查找回调也检查窗口及会话是否仍有效。
- 设置页使用中文确定/取消按钮，改善暗色复选框文字，并提示未命名文档需要先保存才能自动保存。

新增 tests/test_input_workflow.py 的八项交互回归，并追加异常设置类型回归。最终 unittest 66 项中 65 项通过、1 项因目录链接权限跳过；编辑变换 33 项、插件 8 项及搜索 11 项脚本检查通过。Python 编译、浏览器脚本语法和 git diff --check 通过。源码与设置截图均已复查。
