依据 [2026-10-22 全面评审](review-2026-10-22.md)，在基线 `0f3c722`（0.3.6）上修复源码。原始报告与证据保持不变，本记录说明修改后的行为与验收范围。

## P1：数据安全与保存保真

| 报告问题 | 修改后的行为 |
| --- | --- |
| P1-01 原子块未提交输入被外部重载覆盖 | 原子块（公式 / Mermaid / front matter）输入时即时更新 `data-md` 并走与普通输入相同的防抖同步，模型与 dirty 状态不再只在 Ctrl+Enter 提交时更新。外部文件变化处理先同步捕获页面（含原子块和 120ms 防抖窗口）再比较；页面未就绪时拒绝重载，绝不用磁盘版本覆盖未捕获输入。拒绝重载后下次激活仍可重新提示。 |
| P1-02 首次保存后输入不再同步 | 页面重建（保存 / 重载 / 模式切换）时清理原子块引用；所有活动判断改经 `editingAtom()` 校验 `isConnected`，脱离文档的旧引用不再吞掉键盘事件。Esc 取消会先把模型回退到编辑前源码再重建；保存后普通段落输入正常同步并可自动保存。 |
| P1-03 含反引号围栏的缩进代码被拆坏 | 块模型把顶层缩进代码识别为 `code` 块；连续表面把它渲染为持久代码编辑器，`data-md` 保留逐字原文（4 空格缩进、内嵌围栏），未编辑保存字节不变，编辑后才转换为动态长度围栏。列表内的代码以 8 列缩进代码（无围栏）序列化，嵌入多少反引号都保持字面；序列化深度随嵌套自动加 4 列。 |
| P1-04 源码模式另存为改写缩进代码示例 | 代码区识别扩展到缩进代码（列表项内为空行 + 8 列，文档级为空行 + 4 列），其中的图片引用不参与搬迁也不会复制图片。 |

## P2：功能与保真

| 报告问题 | 修改后的行为 |
| --- | --- |
| P2-01 页面命令缺失 | 实现 `jumpToLine(index, offset)`（搜索结果定位并放置块内光标）、`switchTo(index, {caret})`（F2：公式 / Mermaid 进入源码编辑，代码块聚焦代码区）、`toggleCurrentTask()`（任务项勾选 / 普通列表项变任务项 / 段落转任务列表）和 `clearDocumentFind()`；新增 `activeIndex` 取值器。 |
| P2-02 导出漏掉编辑中的原子块 | HTML / PDF / 图片 / Pandoc 四个导出入口都先捕获待提交输入（失败则取消导出并提示），再读取文本。 |
| P2-03 清理异常吞掉完成信号 | 导出任务先恰好一次发出 `finished` 并置终态，再关闭页面、清理临时目录；Windows 文件占用时临时目录延迟重试删除，最终失败也只留给系统临时目录，不再抛入 Qt，取消后不会出现无信号的僵尸任务。 |
| P2-04 实体文字变成标记 | 纯文本节点按语境反斜杠转义：`* ~ `` `、边界处的 `_`（保留 `snake_case` 不转义）、`[ ]`、软换行行首的列表 / 标题 / 引用 / 数字标记，以及主题分割线和 setext 下划线形态；真实格式仍由 em/strong/code 等元素序列化。 |
| P2-05 图片 / 链接转义缺口 | alt 中的 `\ [ ]` 转义；目标地址含空白或括号不配对时自动用尖括号包裹（`<` `>` 编码），成对括号保持裸地址；链接标签中的括号文字同样安全。 |
| P2-06 内联 HTML / 标题锚点 / 缩写丢失 | `<mark> <sup> <sub>` 按内联 HTML 写回；作者的 `{#id}` 通过 `data-md-attr-id` 携带并序列化为 ` {#id}`（TOC 模式仍使用全局 slug，不输出作者锚点）；缩写定义 `*[HTML]: ...` 作为保留原子块，往返不丢。其余 attr_list 形式（class、键值）仍是已知缺口。 |
| P2-07 另存为图片地址括号截断 | 行内图片目标改为扫描器解析：支持反斜杠转义、嵌套配对括号、尖括号地址和标题，`a(b).png` 整体搬迁并复制；搬迁引用保留成对括号不再百分号编码。 |
| P2-08 惰性续行被移出引用 / 列表 | 块模型按产品解析器规则切分：引用和列表吸收非中断性续行（标题、围栏、HTML 块等才中断），列表还吸收无缩进的引用标记行；批量分隔符只在真正的块之间出现，往返结构一致。列表项内普通段落续行使用惰性形式（不再加 4 列缩进，避免改变解析结果）。 |

## 测试稳定性
