# MdNote 0.3.17 发布记录

发布日期为 2026-11-19。

## 更新内容

- 修复实时编辑中创建标题、列表或引用后，中文输入法可能提前写入第一个拼音字母的问题。只有确认后的文字会同步到文档和自动保存。
- 新文档首次保存时，优先取第一个一级标题作为文件名，没有一级标题时取首个非空内容行。建议名称去除常用 Markdown 标记，处理 Windows 文件名限制，并保留最多 60 个正文字符。用户可在保存对话框中修改建议名称。
- 覆盖升级保留含有用户文件的目录，并继续按安装清单清理其余旧版文件和空目录。

## 发布验证

- Python 全量运行 335 项，334 项通过，目录符号链接用例因当前 Windows 环境不支持而跳过。JavaScript 全量 55 项全部通过。
- 使用 Qt 输入法预编辑和提交事件验证新建标题、无序列表、有序列表和引用，组字确认后只保留上屏的中文。文件名建议覆盖实时模式和源码模式。
- 使用独立的注册表项和安装目录验证自定义中文路径安装、覆盖升级和卸载。升级保留用户文档和目录中的自建文件，移除了后续空目录，并隔离了旧版 ICU DLL。
