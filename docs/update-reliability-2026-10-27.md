# 更新下载与安装位置修复 · 2026-10-27

修复用户反馈的 `下载失败：HTTP/2 protocol error`、中断后重复下载，以及升级安装返回默认目录的问题。修复基线为 `a64b030`（0.3.12），正式发布版本为 **0.3.13**。下方保留最初测试包的验证记录；正式安装包与摘要见 [0.3.13 发布记录](release-0.3.13.md)。

## 下载行为

- 更新请求使用 HTTPS / HTTP/1.1，避免当前失败链路中的 HTTP/2 协议错误。证书校验和 HTTPS 重定向限制保留；没有忽略 SSL 错误。
- 连接中断、超时和可恢复 HTTP 错误自动重试，退避为 1 秒、2 秒，此后最多 4 秒；单源最多 3 次。发布者配置多个备用源时，保证每个来源至少有一次机会。
- 保留已下载字节，重试发送 `Range`。只有起始位置、边界和总长度有效的 206 响应能被追加；服务器忽略 Range 返回 200 时清空旧内容，416 时从头重试。HTTP 错误页面不会被写入安装包。
- 应用使用用户数据目录的 `updates` 缓存：网络失败、退出后再次下载可接着已有 `.part`；完整安装包每次复用前重新计算 SHA256。摘要不匹配、无效续传和磁盘错误均不能触发安装。
- 完成后只保留当前安装包和上一份安装包，并清理其他本服务生成的摘要文件名；其他文件不受影响。
- 状态栏显示百分比、已下载 / 总大小和平均速率，以及连接和重试状态。
- 安装包由默认 zlib 改为 solid LZMA 压缩，减少每次更新需要传输的 Qt 运行时体积；具体体积以构建结果为准。

下载服务或当地网络限速时，HTTP/1.1、重试和续传不能保证直连带宽提升。发布者现在可以使用 `scripts/make_manifest.py --mirror` 添加自己的 HTTPS 备用源；主源仍由 `--url` 指定。同一发布的所有来源必须提供完全相同的安装包，沿用一个 SHA256。没有默认添加第三方代理，也没有改写当前 `latest.json` 的 GitHub 地址。

## 安装目录

运行打包应用时，以 `sys.executable` 的父目录作为现有安装位置。通过带 UAC 提权的 ShellExecute 启动安装程序，并把 `/D=现有目录` 作为最后一个参数传入；按 NSIS 约定，参数不加引号，目录中的空格和中文仍保留。

NSIS 初始化明确优先保留 `/D`，包括调用者显式选择默认目录的情况。由于 NSIS 会从 `$CMDLINE` 中移除 `/D`，读取 Windows 原始命令行进行检测。没有显式目录时，依次检查 HKLM 64 位、HKLM 32 位和旧的 HKCU 安装记录，只采用仍存在 `MdNote.exe` 的路径，再回退至默认目录。既有安装专用目录检查和运行进程保护继续生效。

## 验证方式

`tests/test_update_reliability.py` 覆盖协议选择、重试上限、每个备用源、续传 / 200 / 416 / 错误范围、取消与过期回调、缓存跨管理器恢复、缓存损坏与清理、TLS 失败、进度、镜像清单、UAC 取消以及安装目录传递。

其中真实本地 HTTPS 测试使用临时证书，仅对该请求信任测试证书：服务器发送 16KB 后断开，客户端实际再次发送 `Range: bytes=16384-`，剩余内容校验成功。没有使用 `ignoreSslErrors()`；该测试需要可选的 `cryptography`，缺少时跳过。

`tests/test_installer_directory.py` 将生产 `.onInit` 的目录选择代码编译为独立 NSIS 测试程序，实际验证中文空格路径、显式默认路径、旧注册表记录和失效路径回退。注册表读取重定向至随机 HKCU 测试键，测试退出后清理；不安装应用、不修改真实卸载记录。

验证结果：Python 全量 240 项中 239 通过、1 项因目录符号链接权限跳过；最终补充多镜像边界后，相关 39 项复测通过。JavaScript 55 项通过。PyInstaller 构建和 NSIS 编译均成功，打包的更新器、安装启动服务和主窗口模块与当前源码一致。7-Zip 对测试安装包的 3,058 个文件执行完整性检查，结果为 `Everything is Ok`。

最初的测试包为 `.audit-tool/update-2026-10-27/MdNote-test-setup.exe`：**149,609,889 字节**，相比原 0.3.12 正式包的 219,311,183 字节减少 **31.78%**（约 69.7 MB）。SHA256：`1ffdb02277b35d1ce034f6bc9dee5340d38a225b6506437a321be4a5604c1932`。这个测试包保留 0.3.12 版本号，仅用于手动验证；0.3.13 正式安装包另行构建，不使用此测试摘要。

本机日志和构建位于 `.audit-tool/update-2026-10-27/`；[机器可读证据](update-reliability-2026-10-27-evidence.json)保留测试统计、大小对比和摘要。本轮没有对用户截图所处网络进行吞吐量基准测试，也没有执行真实升级安装。
