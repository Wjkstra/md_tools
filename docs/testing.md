# 编辑器回归测试

运行前安装 `requirements.txt` 中的依赖，在项目根目录执行：

```powershell
python tests/test_editor.py
python tests/test_live_editor.py
```

2026-09-30 验证：33 项变换/模型断言、22 项 WebEngine 集成测试通过，进程退出码均为 0。

## 本轮覆盖

- 实际 Qt 键盘输入、回车、下一行继续输入。
- 段落与标题回车后的渲染、空行焦点和光标；列表续行、代码块内换行。
- 中文文本、表情字符的 UTF-16 光标换算；正向/反向选区替换。
- 人为延迟桥接响应时的连续输入、连续回车、多行纯文本粘贴。
- 表格单元格输入同步、列对齐保留、从段落进入表格时提交原内容。
- 块数变化后切换到正确目标块；打开/新建内容刷新。
- 编辑区保持焦点时手动保存与自动保存的落盘内容；源码/预览切换。
- 撤销/重做，以及撤销后新输入使旧重做历史失效。

测试使用真实 QWebEngineView 和 QWebChannel，部分操作由 DOM 事件注入；另有 Qt 原生键盘事件测试。测试文件写入临时目录，不操作用户文档。

## 验证边界

- `isComposing` 回车保护经过事件测试，尚未完成 Windows 输入法候选窗、不同输入法和长时间组字的人工验证。
- 离屏测试环境存在 Chromium GPU 上下文回退日志，不能据此判断实际桌面的显示性能；本轮没有做截图视觉验收。
- PDF/图片/Pandoc 导出、复杂表格格式往返、图片粘贴、长文档性能和安装包不在本轮回归范围内。
- 输入队列目前覆盖桥接期间的普通文字、删除和编辑按键；跨文档切换、鼠标操作与组字同时发生的压力场景仍需补充。
