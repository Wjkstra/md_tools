# MdNote 0.3.15 发布记录

发布日期：2026-10-29。基线：`b69bbdb`（0.3.14）。

## 修复与改进

- **修复列表后无法插入代码块**：在列表空项上按回车退出列表后 Chromium 留下的是裸 `<div>` 而非段落，围栏回车转换与语言联想只识别段落，导致输入 ```` ``` ```` 加回车不生成代码块、反引号被按普通文字保存。现在裸 div 与段落同等对待，并在插入前规范化为段落，避免代码块被嵌套吞掉。
- **引用 / 列表内围栏代码保存保真**：Python-Markdown 不解析引用与列表项内的围栏，反引号围栏会被降级为行内代码并在保存时破坏围栏。这些块现在整体以逐字源码原子呈现（点击编辑源码），保存与原文逐字一致；列表 8 空格缩进代码仍正常渲染编辑。
- **引用定义精确原子化**：文档含引用 / 脚注 / 缩写定义时，普通行内链接段落不再被整体锁定为原子，段内的行内公式恢复即时渲染。
- **代码块删除优化**：空代码块内 Backspace 整块删除（Typora 式，可撤销，相邻段落保持空行分隔，光标回到前段末尾或后段开头）；段落 / 标题 / 引用末尾紧邻代码块时按 Delete 不再反向清空本段文字。
- **修复引用开头 Backspace 不去格式**：结构换行导致偏移判定多 1。
- **修复 Ctrl+K 无选区时插入空链接**：现在插入可编辑的占位链接，源码模式行为一致。
