# MdNote 项目文档

本目录包含 MdNote 的完整技术文档，可直接用 MdNote 自身打开阅读
（Mermaid 图表、数学公式均可实时渲染）。

## 阅读顺序

| # | 文档 | 面向读者 | 内容 |
| --- | --- | --- | --- |
| 1 | [架构设计](architecture.md) | 所有开发者 | 进程 / 线程模型、分层架构、模块职责、QWebChannel 契约、关键流程 |
| 2 | [数据模型](data-model.md) | 编辑器开发者 | 块模型、块类型、偏移与间隙不变量、编辑变换 |
| 3 | [性能设计](performance.md) | 编辑器开发者 | WebEngine 渲染、防抖节流、缓存、长文档优化方向、基准数据 |
| 4 | [安全模型](security.md) | 所有开发者 | 威胁模型、进程隔离、净化管线、导航控制、安全清单 |
| 5 | [插件开发](plugin-development.md) | 插件作者 | Python-Markdown 扩展机制、插件结构、API、完整示例 |
| 6 | [开发指南](development.md) | 贡献者 | 环境搭建、调试、测试、编码规范、构建与发版 |

> 初次接触建议先阅读根目录 [README](../README.md) 的项目介绍，再从《架构设计》开始。
> 文档与代码保持同步；修改架构时请同时更新对应文档。

## 文档约定

- 文档中的代码示例经过实际验证，可直接运行。
- 标识 **（规划中）** 的能力描述的是目标设计，可能尚未在当前版本实现。
- 路径若未特别说明，均相对于仓库根目录。
