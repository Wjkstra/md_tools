# MdNote 0.3.16 发布记录

发布日期：2026-11-03。

## 二次启动修复版（fix2）

- fix1 仍有覆盖安装后无法启动的场景：清单由 Python Windows 文本模式写出，`\r\n` 被翻译成 `\r\r\n`，而安装程序固定按两个字符截断行尾，删除路径多出一个 `\r`，原 0.3.16 携带的 `icuuc.dll`、`icudt78.dll` 实际未被移除（已对线上 fix1 安装包解包核实）。
- fix2 安装程序逐字符去除行尾 CR/LF，兼容两种清单；若冲突 DLL 已不在清单中（fix1 升级后的遗留孤儿文件），则改名为 `*.mdnote-disabled-N` 移离 DLL 搜索路径：保留字节、不覆盖已有备份，文件被占用时提示并以错误码 4 退出。
- 打包脚本改为写字节，清单重新生成时不再把自身计入安装文件（重复生成结果一致）。
- 安装包 `MdNote-Setup-0.3.16-fix2.exe`：154,438,568 字节，SHA256 `c2ee405ac05b5dc2bdfd6c6ca3b5611a29642ec0723581b45a890cee4e2fe321`。7-Zip 完整性通过（3072 文件）；解包后无任何 `icu*.dll`、安装清单为规范 CRLF 且不含自身；隔离环境程序冒烟启动通过；以真实 fix1 清单加孤儿 DLL 模拟覆盖升级，隔离改名、用户文件保留、卸载清理和注册表/开始菜单移除均用实际安装包静默验证通过。
- 卸载程序会清理隔离改名的文件，避免残留占用专用目录导致无法原位重装。
- Python 全量 331 项：330 通过、1 项因目录符号链接权限跳过（346 秒）；JavaScript 55 项全部通过。
- 构建时因机器内存紧张将 NSIS solid LZMA 字典由 32MB 降为 8MB，仅影响压缩率，安装内容与仓库脚本一致（功能代码逐行相同）。
- 版本号仍为 0.3.16：已安装原 0.3.16 或 fix1 的用户需手动下载 fix2 覆盖安装，同版本自动更新不会提示；0.3.15 及更早用户的自动更新会直接取到 fix2。未在本机直接覆盖用户实际安装。

## 启动修复版（fix1）

- 原安装包误将构建机上 Poppler 的 `icuuc.dll` 收入程序目录，该库不提供 Windows Qt6Core 需要的未加版本后缀的导出函数，导致启动时报 `DLL load failed while importing QtCore`（Windows 错误 127）。
- 修复版打包时排除冲突的 ICU 库。旧版安装清单中的这些文件会在覆盖安装时被移除；不属于安装清单的用户文件不受影响。
- 修复版安装包：`MdNote-Setup-0.3.16-fix1.exe`，151,470,134 字节，SHA256 `a6bd01f5348552bc1bc31867f3dcf9145791e0951abd126920733637f248b7f8`。7-Zip 完整性检查通过；打包后的 Qt6Core 加载与隔离环境中程序启动通过。
- 修复后 Python 全量 326 项：325 通过、1 项因目录符号链接权限跳过；JavaScript 55 项全部通过。首次并行打包的回归在复选框测试失败后停滞，单独复测相关套件及无打包负载的全量回归均通过。
- 由于修复版仍使用 0.3.16 版本号，已安装原 0.3.16 的用户需要下载修复版并覆盖安装，不能依靠同版本自动更新。未在本机直接覆盖用户安装。

## 原 0.3.16 记录
