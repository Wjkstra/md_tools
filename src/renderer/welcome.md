# 欢迎使用 MdNote 👋

MdNote 是一款注重**性能、安全与可扩展性**的 Markdown 编辑/阅读工具。

## 两种编辑模式

- **实时模式（默认）**：点击任意段落即可编辑该块的 Markdown 源码，离开自动渲染
- **源码模式**：按 `Ctrl+/` 切换，使用 CodeMirror 全文档源码编辑

## 常用快捷键

| 功能 | 快捷键 |
| --- | --- |
| 保存 | `Ctrl+S` |
| 打开文件 / 文件夹 | `Ctrl+O` / `Ctrl+Shift+O` |
| 加粗 / 斜体 | `Ctrl+B` / `Ctrl+I` |
| 删除线 | `Ctrl+Shift+X` |
| 代码块 | `Ctrl+Shift+K` |
| 插入图片 | `Ctrl+Shift+I` |
| 切换源码 | `Ctrl+/` |
| 专注模式 / 打字机模式 | `F8` / `F9` |
| 侧边栏 | `Ctrl+J` |

## 试试这些功能

- 输入 `[toc]` 回车生成**自动目录**
- 任务列表：

- [ ] 点击复选框即可勾选
- [x] 已完成事项

- 代码块（语法高亮 + 一键复制 + 行号）：

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"
```

- 数学公式：行内 $a^2 + b^2 = c^2$，块级：

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

- Mermaid 图表（在设置中开关）：

```mermaid
flowchart LR
  A[写下想法] --> B[整理结构] --> C[导出分享]
```

- 表格：**单击选中单元格、再次单击编辑**，拖动列右边框调宽，右键增删行列

## 安全与性能

- 渲染内容经 DOMPurify 净化，脚本、内联事件、危险样式均被移除
- 长文档采用**视口虚拟化**：无论文档多少块，DOM 中只保留屏幕附近的内容
- 图片使用本地安全协议加载，外链一律交由系统浏览器打开
